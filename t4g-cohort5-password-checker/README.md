# Password Strength Checker

## About the Project

The Password Strength Checker is a simple Python program that checks how strong a password is. It evaluates a password based on different security requirements and gives a strength rating.

The program checks:
- If the password is at least 8 characters long
- If it contains an uppercase letter
- If it contains a number
- If it contains a special character

After checking these requirements, the program rates the password as:
- Weak
- Fair
- Strong

## How to Run the Program

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the Python file using:
python3 password_checker.py
